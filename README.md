# seaLeye.run

Bring your app. `sealeye run` reads it, asks a few questions in your language, writes a
deployment plan you can read, and on "yes" runs it on AWS and hands you a report.

Demo build for October 2. Rules in CLAUDE.md, scope in docs/SCOPE.md, progress in
docs/PROGRESS.md, brand in brand/BRAND.md. Internal component names (deployme) are not
the product name.
