# Beneficiary Lookup

Confirms who a payment is going to: given a saved payee reference, it returns the payee's display name, the institution holding their account, and whether that payee has been verified.
Owned by the Payments Product team at Northline Bank, for branch staff reviewing outgoing payments before they release them.
Depends on the nightly beneficiary extract from the payments system of record. Reference data only: no balances, no payment instructions, no customer records.
Used by the branch payment review screen and by payee search in the servicing desktop. Questions and data corrections go to Payments Product.
