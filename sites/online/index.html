The portal Phase 1

seaLeye.online is where a platform team will see each environment, its status read from the platform itself, the plan it was built from, and the needs developers have run into. It arrives in Phase 1.

Developers can start today

seaLeye.run is the command. Bring an app, answer a few questions, read the plan, and say yes. Install it from sealeye.run, then run sealeye run in your app's folder.
