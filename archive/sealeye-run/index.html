cd your-app && sealeye run

You have an app in a folder. seaLeye reads it, asks you a few questions, provisions the environment you need, and gives you back a URL. You never need to know what a stack is. Just sealeye run and you are off to the races!

Install

At Northline Bank: your platform team publishes seaLeye to your internal registry. Copy and paste this line into your Terminal to get seaLeye on your laptop. That's it. You're ready to run!

$ npm install -g @northline/sealeye

Start from your app

$ cd your-app && sealeye run

Your browser does not tell this page where the folder lives, so set the path in front of the name if it is not right. Open Terminal and paste.

Nothing is uploaded. The folder name never leaves this page.

What you get back

  • A URL that works as soon as it is live, and stays the same every time you deploy again.
  • Logs and metrics collected from the first request, with nothing to set up.
  • A plan in your folder saying what was built and what was assumed, yours to keep and to edit.
