# Orders

Keeps the supply orders branches place: given an order id, it stores the branch, the item and the quantity, and returns an order by its id.
Owned by the Branch Operations team at Northline Bank, for branch staff ordering supplies and the central team filling them.
Keeps its orders in a table the platform provides, named by the ORDERS_TABLE setting. Orders only: no prices, no supplier accounts, no customer records.
Used by the branch supplies screen. Questions and corrections go to Branch Operations.
